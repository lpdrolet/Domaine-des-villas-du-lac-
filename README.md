# Domaine des Villas du Lac

Site statique du dossier de développement immobilier de la rue des Villas, secteur Deauville, Sherbrooke (Québec).

## Contenu
- `index.html` — tableau de bord et vue d'ensemble
- `terrains.html` — inventaire des lots et propriétaires
- `lot.html?id=...` — fiche individuelle dynamique de chaque terrain suivi
- `routes.html` — construction des routes et phasage
- `finances.html` — plan d'affaires et scénarios économiques
- `documents.html` — documents, sources et liste de diligence
- `assets/` — styles, données, logo et schéma de localisation
- `documents/` — exports de données du projet

## Statut des données
Les données sont un document de travail au 30 août 2026. Les informations du rôle municipal, les informations internes et les hypothèses financières sont distinguées. Les titres du registre foncier, les plans d'arpentage, les confirmations municipales et les études professionnelles priment.

## Hébergement
Le site ne requiert aucune compilation. Le dossier racine peut être publié directement sur Netlify, GitHub Pages ou tout hébergement statique.
